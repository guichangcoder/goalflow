# 目标流 GoalFlow

> 把一整年画成一张图，让"当下最重要"自己发光。

一个**单文件、纯本地、双击即用**的可视化时间管理工具。没有账号，没有云端，没有订阅——你的目标、客户的跟进、想了三年没动的书，数据全在你自己电脑里。

作者：史贵昌（十年企业数字化咨询顾问）

---

## 它解决什么问题

待办清单越列越长，每天睁眼先看一眼，然后很自然地——先做最简单的那几条。真正重要的那件事，"等一下再做"。一天结束，忙得脚不沾地，回头一看，忙而无功。

四象限的道理每个职场人都懂，可"重要不紧急"那一类，从来没被真正安排进时间表。

**目标流不是来教你"要事第一"的——它是来让你"看见"的。看见，才有选择。**

## 核心功能

**1. 目标粘进去，自动画成一条桑基河**
整段年度目标粘贴进来，自动解析成目标树，画成桑基图：带子越宽越重要，颜色越暖越紧急。你的精力错配，一眼看见。

**2. "当下最重要"算法替你定，还告诉你为什么**
按「重要度×10 + 期限临近加权」从整棵目标树拽出唯一那件事，放在页面最顶上的英雄卡里——已逾期？期限临近？还是长期主线该提前投入了？每天不用再"纠结先做哪个"。

**3. 时间像地图一样缩放：年 → 月 → 周 → 日**
年度总览看 12 个月精力扎堆在哪，每周看 7 天节奏，每日看 7 个时段。每次缩放，精力比例尺、流图、四象限、聚焦清单全部联动切换。"本周最重要"和"今日最重要"不是同一件事。

**4. 四象限不用填表，拖一下就好**
把任务卡拖进对应象限，重要/紧急分值自动归位，流图条带、英雄卡、聚焦清单实时重新计算。

**5. SMART 体检 + 对话式拆解**
"提升销售能力"这种目标，体检面板逐项亮灯：不具体、不可衡量、无限期。点「对话拆解」，助手一项项追问，把模糊愿望整成有指标、有期限的行动，一键拆成子任务。

## 快速开始

**方式一：在线用**（无需安装，推荐）
浏览器打开：**https://guichangcoder.github.io/goalflow/** —— 数据存在本地浏览器，打开即用。

**方式二：下载到本地**
下载 `index.html`（或 `goal-focus.html`，两者内容相同），双击打开。拷到任何电脑都能用，不依赖网络。

## 数据与隐私

- 所有目标数据仅存储于你浏览器的 localStorage，**不上传任何服务器**
- LLM 对话功能使用你自己的 DeepSeek API Key（页面内填写，仅存于本机浏览器）
- 无账号体系、无遥测、无第三方追踪脚本

> 提示：localStorage 随浏览器缓存清理而丢失，重要目标请定期自行备份。
