1 输入目标（自由文本）

这是什么 · 怎么读这张图

桑基流图：从「目标」流出的每条带子代表一份精力投入。带子越宽 = 越重要（值得投入的精力越多）；颜色越暖（红）= 越紧急。战略主线（重要不紧急）是宽阔的冷色河，火情（重要且紧急）是又宽又红的急流。

金色发光的那条就是「当下最重要」——算法按 重要度×10 + 期限临近加权 选出最该立刻动手的具体任务，并沿 目标→方向→任务 把它一路点亮。

时间尺度缩放：右上角像地图一样可切换 年度总览 / 每月 / 每周 / 每日，看清不同时间颗粒度下的精力重点；下方「全年精力节奏」把一年拆成 12 个月，看精力在哪几个月扎堆。

四象限校准：图下方把任务按「重要 / 紧急」铺成四象限，直接把卡片拖到目标象限即可重设优先级，与流图、英雄卡实时联动。

SMART 智能对话：左栏「SMART 体检」会检查每个目标是否够具体、可衡量、有期限；点「对话拆解」可让助手逐项提问补齐，或一键拆成子任务。

层级用缩进 / 编号(1. 1.1) / 项目符号(- •)。首行自动作为「目标根」。日期如「周五前 / 本周内 / 3月15日 / 月底」会被自动识别为期限；「每天 / 每周 / 每月 / 今年」会被识别为时间尺度。
